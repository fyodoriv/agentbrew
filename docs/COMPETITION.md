# AgentBrew — Competition Analysis

## TL;DR

Keep agentbrew as a small owner of desired configuration and continue selective
delegation. Upstream tools overlap more than the old analysis claimed. No
replacement was verified against all data-preservation and multi-surface
requirements in this review. Stars measure interest, not parity.

All 55 tracked entries were checked on 2026-11-01. Upstream README statements
remain upstream claims until tested in the native runtime. The
[quarterly decision](competition/dissolution-reviews/2026-Q4.md) records the
contribution pulse, triggers, delegation decisions and remaining boundaries.
Skills compatibility is **partial**: new targets still require native-runtime
validation. The weekly recurring task remains due.

## Purpose

Check alternatives before extending agentbrew. Prefer GET → WRAP → CONTRIBUTE
→ ABSORB. Preserve user edits, organizational-overlay routing and explicit
support-policy exclusions.

## Review Cadence

Refresh stale rows weekly and dissolution quarterly. Follow
[RECURRING.md](../RECURRING.md) for exact acceptance. Reading a source does not
authorize installing a client or changing its support.

## Safe Refresh Workflow

1. Read current metadata, documentation and release notes.
2. Update the snapshot. Distinguish repository releases from separately
   versioned npm packages and monorepo components.
3. Reassess ownership and safety. A small star count is not inactivity; an
   inaccessible repository is not proof of death.
4. Run `npm run docs:competition` and the declared changed-file gate.
5. Advance the cadence only after every required acceptance condition passes.

### What to Watch For

- Caliber now mirrors multiple configuration surfaces and exposes sync status.
- Bridle installs and translates several component kinds across profiles.
- ai-rules-sync resumed activity and documents user-scope native assets.
- syncode2 changed to explicit Git-source adoption and conflict backups.
- MCPick now has multiple clients and portable skills.
- conforme documents multi-surface conversion and generated-file cleanup.
- Skills Manager, OpenViking and gstack grew materially, but interest does not
  establish configuration-ownership parity.
- Tons of Skills separates canonical content from native adapter verification.
- Skills Compat Manager is reachable; Nix Agentic Tools documents declarative
  modules. Old availability claims must not drive their verdicts.
- Ruler, Agent Switchboard, agents_sync, Cyncia and hosted control planes remain
  in the quarterly watch list even when absent from the freshness tracker.
