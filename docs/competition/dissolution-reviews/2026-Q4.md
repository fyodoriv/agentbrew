# Q4 2026 dissolution review

Decision date: 2026-11-01. Keep the current orchestrator and selective
delegation. Do not expand native support from a README alone. The weekly
competitor research is fresh, but its new-target compatibility acceptance is
still incomplete. No missed Q3 review is represented as completed.

This is a source review, not a migration trial. Public GitHub metadata,
release notes and current documentation were read. No live configuration,
connector, plugin, credential or upstream thread was modified.

## Contribution pulse

The 90-day cutoff is 2026-08-03. A maintainer event means a public comment,
review or submission with OWNER, MEMBER or COLLABORATOR association, or a
recorded merge. A maintainer-authored submission shows active work; it is not
a response to an external contribution. An ordinary author's update does not
count as maintainer engagement. Missing public engagement does not prove that
no private discussion occurred.

found eight PRs, all closed unmerged. None was created since 2026-07-01.
The older list also contains community proposals; those are dependencies,

## Fatal-gap list

Seven **remaining acceptance boundaries** are retained. They are not seven
claims that no upstream product implements any part of the feature. Current
overlap reduces the work a future replacement trial must do.

| Boundary | Current overlap | Proof still needed before retiring the local owner |
|---|---|---|
| Commands, hooks and instructions | Caliber, Bridle, Agent Switchboard and native-asset federation cover parts. | Required targets/formats, caller scope and user edits survive refresh and removal. |
| Multi-surface drift | Caliber sync status, Agent Switchboard state and conforme check/status overlap. | Desired and actual state agree across the installed surfaces, including unmanaged user data. |
| Scheduled repair | agents_sync documents a daemon; Caliber uses hooks. | Scheduling, offline failure and bounded recovery match the current machine contract. |
| Unified declarative state | Agent Switchboard, Cyncia, syncode and Nix modules supply alternatives. | One reviewed manifest covers required surfaces and has safe ownership/migration semantics. |
| Cross-agent definitions | Bridle, Cyncia and conforme translate agents; current agentbrew supports native Codex TOML. | Native runtimes load correct content without unsafe permission or format widening. |
| Organizational delivery | Hosted catalogs and plugins overlap distribution. | Generic base plus private overlay selection preserves entitlement and identity boundaries. |
| Portable bundles | Git-source tools and package managers overlap export and restore. | A full multi-surface round trip preserves source receipts, local edits and recovery. |

The count remains seven because no full acceptance boundary was retired by a
native replacement trial. Counting feature labels would overstate progress.

## Recommendations

1. Preserve existing delegation and deliberate exceptions. The new
   `validate-skills-targets-2026-11` task owns the unverified target delta and
   exact native-runtime blocker. This is the remaining weekly acceptance,
   not a reason to claim that a refresh is fully complete.
2. Measure maintenance capacity and story evidence before changing the kill
   decision. The new `measure-dissolution-capacity-2026-q4` task records the
   missing owner-supplied measurements; do not use commit counts as a proxy.
3. Keep public contribution steps within their existing approval boundary.
   `contribute-trust-building-pr-skills-cli` and
   `bridle-opencode-path-issue` remain blocked publish tasks. Their prepared
   content is not a public contribution until submitted with exact approval.

No capability is absorbed or deleted by this review. Keep the working
ownership guards, source receipts, rollback and overlay boundaries. Any future
replacement needs a pre-registered scratch-data trial and native runtime
controls before source removal.

the decision more than popularity. The existing recurring questions supplied
the strategic context, so repeating generic business questions would add no
new evidence. Missing capacity and story-outcome measurements remain explicit.
