# Disposable MCPM runtime control

Measure the actual published MCPM 2.15.0 CLI in an isolated Ubuntu job.
The fixture server advertises one tool only when it receives its exact
synthetic parent marker. Use the registered Agentbrew stdio probe to
complete the proxy handshake. Both entries use the same Node server.
The raw override is the baseline and the managed projection is the
candidate. Require zero tools for the raw override, one for the managed
entry, zero saved marker values, and zero network access during execution.
A dependency setup failure is inconclusive. No live configuration or data
is used.
