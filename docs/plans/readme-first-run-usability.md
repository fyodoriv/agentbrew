# Measure whether first-time users can start from the README alone

- **Hypothesis:** A shared protocol gives project owners comparable first-run
  measurements and shows where a README leaves new users stuck.
- **Measurement:** Check both skill links, the run template and the skill
  eval. On each app, log three first runs from the README alone. Calculate
  the median elapsed time to the first verified result.
- **Success:** The eval expects three unfamiliar people, a clean start,
  no coaching, and a five-minute median target. The protocol maps friction
  over five minutes to a P1 task. A project meets the live target when all
  three finish unassisted and the median is at most five minutes.
- **Pivot:** If the median still exceeds ten minutes after two README-fix
  rounds, revise the install path.
- **Anchor:** `readme-human-first-run-test` and the archived Minsky
  user-test protocol. The Skill eval checks the protocol. Verified human
  sessions provide the usability result.
