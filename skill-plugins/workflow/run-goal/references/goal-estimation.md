# Estimate and calibrate goals

Before execution, inventory every deliverable and acceptance gate. Include
research, implementation, review, verification, delivery, and rollout.
Map dependencies, blockers, parallel capacity, and the critical path.
For a rolling backlog, date the scope snapshot and forecast new arrivals
separately. List each excluded or blocked item and what would bring it in.

Inspect current evidence and look for comparable completed work. Research
unknowns that could change the estimate. If direct evidence is sparse,
extrapolate from an explicit comparable or a bounded sample. State the
assumptions, confidence, and what would change the forecast. Give a low,
likely, and high range for active effort and elapsed time. Include queue,
review, and external waits in elapsed time. Estimate blocked work
conditionally if its release date is unknown.

Save the original scope and estimate before execution. Update the forecast
when evidence changes and keep the original for comparison. On every goal
closeout, compare the estimate with actual effort, elapsed time, and output.
Record missing measurements and separate scope changes from estimation
error. Save reusable calibration evidence, then update this method or its
evals with one concrete lesson. If the evidence supports the current
method, record why and add the observed case to the calibration history.
